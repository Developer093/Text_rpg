# ⚔ 작은 왕국의 모험

왕국을 위협하는 드래곤을 물리치는 간단한 RPG 게임입니다.

## 🎮 바로 플레이하기

👉 **웹 버전**: 이 저장소의 GitHub Pages 주소에서 바로 플레이할 수 있어요. (설치 필요 없음)

## 🐍 파이썬으로 실행하기

| 파일 | 설명 | 실행 |
|---|---|---|
| `text_rpg.py` | 터미널(콘솔) 버전 | `python text_rpg.py` |
| `text_rpg_gui.py` | 창이 뜨는 GUI 버전 (tkinter) | `python text_rpg_gui.py` |

추가 설치 없이 파이썬 3만 있으면 실행됩니다.

## 📜 게임 방법

- **마을 광장**에서 숲, 던전, 상점, 여관, 드래곤의 산 중 원하는 곳으로 이동해요.
- **전투**: 공격 / 방어(받는 데미지 절반) / 포션 / 도망
  - 10% 확률로 치명타
  - 몬스터가 가끔 포션을 떨어뜨려요
- 경험치를 모아 **레벨 업**하면 능력치가 오르고 HP가 회복돼요.
- **상점**에서 포션, 철검, 가죽 갑옷을 살 수 있어요.
- 충분히 강해지면 **드래곤**에 도전하세요! (보스전은 도망 불가)

## 🛠 구조

- `index.html` — 웹 버전 (HTML + JavaScript, 파일 하나)
- `text_rpg.py` — 콘솔 버전
- `text_rpg_gui.py` — GUI 버전. 게임 로직(`Game`)과 화면(`App`)이 분리되어 있어요.
